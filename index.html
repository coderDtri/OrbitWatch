How it works, in 5 steps

  1. NASA takes sky pictures. The SPHEREx telescope maps the whole sky every six months in 102 colors of infrared light.
  2. Compare the same spot on different dates. Fixed stars don't move. Close objects do.
  3. Score each change. Movement, image clarity and agreement with other data raise the score. Signs of an image error lower it.
  4. People check. Did it really move? Is it a camera glitch? Does it need an expert?
  5. Experts confirm with official data. A change is a lead, not a discovery. OrbitWatch never claims to have found Planet X.
Why Planet X is hard: a single SPHEREx image may be too faint to show a planet that far away, so finding one would take many pictures and expert follow-up.

Use real NASA images in OrbitWatch

  1. Find exposures that cover your spot: use the button above (IRSA SPHEREx Data Explorer).
  2. Pick two from different dates. Prefer small cutouts: full SPHEREx files are large (other teams report about 69 MB each).
  3. Know the files. They are FITS files with layers such as IMAGE, VARIANCE and FLAGS. One image spans a range of wavelengths, it is not a single color.
  4. Make two PNGs of the same patch, same orientation and scale (for example with Python and astropy). If they are not aligned, stars will seem to jump.
  5. Load them below, then Blink, Compare or use the Date slider.
  6. Before calling anything new, check it against JPL's small-body tools.
